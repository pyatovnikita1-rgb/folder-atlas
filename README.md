# Folder Atlas

Folder Atlas показывает на карте, чем занят диск Mac. Кнопка «Разобрать с Codex» открывает чат с готовым запросом о том, что можно очистить.

- [Сайт](https://pyatovnikita1-rgb.github.io/folder-atlas/)
- [Предварительный выпуск 0.3.9](https://github.com/pyatovnikita1-rgb/folder-atlas/releases/tag/v0.3.9)

Этот репозиторий содержит только опубликованный лендинг и готовые бинарные выпуски.
Исходники приложения здесь не размещены. Web-файлы поставляются из отдельного
канонического проекта; изменения сайта публикуются его владельцем.

Приложение 0.3.9, build 15: macOS 13 или новее, Apple Silicon (arm64).
Подпись ad-hoc; Developer ID и нотариализация Apple не подтверждены.
Установка скачанного файла на другом Mac и поведение Gatekeeper не проверены.
Приложение не удаляет файлы; решение и действия по очистке выполняет пользователь.

Оставьте Folder Atlas открытым и отправьте запрос в Codex. Агент разберёт сохранённый снимок или предложит выбрать область сканирования.

In 0.3.9, choose “Review with Codex” and send the prepared request. Keep Folder Atlas open while Codex reviews a saved scan or helps you start one.
