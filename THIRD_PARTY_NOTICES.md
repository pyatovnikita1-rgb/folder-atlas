# Сторонние ресурсы

Inter, Nunito Sans, PT Serif, Golos Text, Oswald, IBM Plex Mono и Unbounded
распространяются по SIL Open Font License 1.1. Тексты лицензий с именами
правообладателей находятся рядом со шрифтами в assets/fonts/ и assets/fonts/preview/.

Finder и macOS являются продуктами Apple Inc. Значок Finder используется для
обозначения перехода в Finder. Этот проект не связан с Apple и не одобрен Apple.

Видео используют демонстрационные данные. Первый ролик показывает разбор диска с Codex в версии 0.3.9, второй — работу с картой в одной из предыдущих сборок.
